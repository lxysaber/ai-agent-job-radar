## 推荐学习顺序

1. Python/FastAPI + LLM API/结构化输出：先搭好可运行、可测试的后端基础。
2. Tool Calling/MCP + 单 Agent：建立工具白名单、权限边界和错误恢复。
3. RAG：补齐检索、重排、引用和离线评测，而不只做聊天演示。
4. LangGraph 等工作流：把多步任务建模为可观察、可恢复的状态机。
5. 部署与评测：把延迟、成本、命中率、工具失败率纳入项目验收。
