# AI Agent 面经收集箱

将 OpenCLI 或浏览器保存下来的公开讨论/面经内容放在这个目录，然后运行：

```bash
python3 scripts/build_interview_notes.py --input data/inbox/interviews --out notes/interviews
```

支持 `.json`、`.md`、`.txt`。纯文本建议在开头补充以下字段，以提高笔记质量：

```text
公司：示例公司
岗位：AI Agent 后端开发工程师
轮次：一面
链接：https://www.nowcoder.com/discuss/...
```

笔记只保存原帖链接、考点、问题与复盘清单；发布前请人工核对原帖，不要把私密信息或 Cookie 放进收集箱。
